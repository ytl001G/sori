# Sori 음성 편집기 — 기능 명세

Audacity의 핵심 편집 기능 + FL Studio식 트랙 화면·믹서, 깔끔한 UI와 상식적인 단축키.
고급 기능(VST, 매크로, 분석 도구, 복잡한 라우팅)은 넣지 않는다.

## 1. 파일
- 열기 (Ctrl+O): 오디오(WAV/MP3/FLAC/OGG/M4A) → 각각 새 트랙 / `.vproj` → 프로젝트 열기. `.vproj` 파일을 더블클릭해도
  그 프로젝트가 열림 (Sori가 꺼져 있으면 켜면서, 켜져 있으면 그 창에서 — 저장 안 한 변경은 먼저 물음)
- 최근 파일 (파일 > 최근 파일): 최근 연 프로젝트·오디오 8개. 없어진 파일은 누르면 목록에서 빠짐
- 드래그&드롭: 오디오 파일을 창에 놓으면 새 트랙 (트랙 위에 놓으면 그 트랙의 놓은 위치에)
- 새 프로젝트 (Ctrl+N): 샘플레이트는 설정의 "새 프로젝트 샘플레이트"
- 대본 넣기 (파일 > 대본 넣기…): .txt / .csv / .tsv / .xlsx → 지금 프로젝트가 대본 녹음 프로젝트가 됨 (§5-5). 대본 프로젝트에서
  넣으면 새 대본이 기준
- 보통 프로젝트로 바꾸기 (파일 > 보통 프로젝트로 바꾸기…, 대본 프로젝트에서만): 테이크가 모두 트랙이 됨
- 프로젝트 저장 (Ctrl+S) / 다른 이름으로 저장 (Ctrl+Shift+S) — `.vproj`: 트랙 배치·볼륨·팬·트랙 효과·마스터 효과·
  마커·빠르기·클립 볼륨/페이드·소리 데이터 전부. 소리는 압축해서 저장 (16비트 소리는 그대로, 그 밖에는 24비트로 맞춤:
  귀로 구분 못 하는 차이, 크기는 약 1/4~1/2). 압축은 쉬는 동안 미리 해 둠 (저장할 때 멈추지 않게). 예전 버전 파일도 열림
  (새 파일은 예전 Sori에서 안 열림)
- 내보내기 (Ctrl+E): WAV(16bit/24bit) / MP3(128/192/320kbps), 범위 = 전체 / 선택 구간 / 마커 구간별(구간마다 파일 하나,
  폴더 고르기, "01 마커이름.wav"). 기본 형식은 설정에서. 트랙 = 모두 섞기 / 지금 트랙만(그 트랙을 솔로로 들은 그대로:
  트랙 효과·볼륨·팬 + 마스터 효과, 트랙이 2개 이상일 때 보임)
- 자동 저장: 설정한 간격(기본 2분)마다 몰래 저장. 갑자기 꺼지면 다음에 켤 때 [복구] / [지우기]
- 자동 백업: 작업 중 10분마다, 바뀐 게 있으면 지금 작업 상태(저장 안 한 변경 · 저장 안 한 새 프로젝트 포함)를 앱 전용
  폴더에 백업. 프로젝트마다 최근 10개, 같은 소리는 백업끼리 한 번만 저장 (10개여도 소리는 거의 한 벌). 30일 동안 새
  백업이 없는 프로젝트의 백업은 지움 (지금 연 프로젝트는 빼고). 파일 > 백업에서 열기… = 모든 프로젝트의 백업 목록(지금 프로젝트가 맨 위)에서
  골라 저장 안 한 프로젝트로 엶 (원래 파일은 그대로, 저장하면 원래 파일 이름을 먼저 제안). 못 만들면 알림만
- 저장 안 한 채 닫기/새로 만들기/열기 → 앱 자체 확인 창 [저장] [저장 안 함] [취소] (저장을 취소하면 그대로 머묾)

## 2. 화면
- 위 바: 메뉴(파일·편집·녹음·트랙·마커·보기·효과), 재생 컨트롤 + 메트로놈, 현재 시간, 빠르기(BPM)·박자·박자 격자·스냅,
  확대/축소, 믹서, 효과 패널, 설정, 단축키, 테마 전환
- 왼쪽: 트랙 헤더 — ⠇ 손잡이(끌어서 순서 옮기기, Ctrl+Alt+↑/↓), 이름(더블클릭 수정), 효과(트랙 효과 열기), M(음소거),
  S(솔로), 볼륨, 팬, 삭제
- 트랙 추가: `+ 트랙` = 지금 트랙 아래에 빈 트랙, 옆 [▾] = 빈 트랙 · 지금 트랙 복제 (Ctrl+Shift+D) · 목소리 트랙 ·
  배경음악 트랙 · 효과음 트랙 (트랙 메뉴에도). 새 트랙은 모두 지금 트랙 바로 아래에 생기고 지금 트랙이 됨
  - 복제: 소리·효과·볼륨·팬까지 통째로, 이름 "… 복제"
  - 목소리: EQ '목소리 또렷하게' + 컴프레서 '목소리 고르게' 켜짐 / 배경음악: 볼륨 −12 dB, EQ 2.5 kHz −3 dB /
    효과음: 볼륨 −6 dB. 만든 뒤에는 보통 트랙과 같음
- 트랙 > 이름순 정렬: 트랙을 이름순으로 (가나다 다음 A-Z, 이름 속 숫자는 크기대로: 보컬2 → 보컬10). 언제나 같은 순서
  (거꾸로 없음), Ctrl+Z로 되돌림. 대본 모드에선 흐리게 — 테이크는 대본에 넣은 그대로
- 가운데: 타임라인 — 시간 눈금(박자 격자 켜면 마디·박), 마커, 클립 블록(이름 띠 + 파형 또는 스펙트로그램), 재생 위치선, 선택 영역
- 오른쪽: 효과 패널 (F8) — 마스터 또는 한 트랙의 항상 걸린 효과 (§5-1)
- 아래: 믹서 (F9) — 트랙마다 세로 볼륨·팬·레벨 미터·클리핑 표시·M/S·효과 버튼, 맨 오른쪽 마스터. 위쪽 경계를 끌어 높이 조절
- 맨 아래: 상태 줄 — 안내 문구, 선택 구간 시간, 샘플레이트·트랙 수·길이
- 스펙트로그램 보기 (보기 메뉴): 타임라인 전체를 파형 대신 주파수 그림으로 (모든 트랙 함께). 화면 보기일 뿐이라
  실행취소 · 저장 대상 아님. 앱을 켤 때마다 파형으로 시작하고, 켜 둔 동안은 다른 프로젝트를 열어도 그대로
- 찾기 (Ctrl+F, 편집 메뉴): 타임라인 오른쪽 위에 작은 찾기 칸이 뜸. 글자 일부만 맞아도 찾음 (대소문자 · 띄어쓰기 무시)
  - 보통 프로젝트: 트랙 이름. 찾으면 그 트랙이 지금 트랙이 되고 화면에 보이게 스크롤
  - 대본 프로젝트: 왼쪽 목록에 보이는 대사만 (탭 · '녹음 안 한 것만'으로 걸러진 그대로, ↑/↓와 같은 범위) — 대사 번호
    (철수-003)와 대사 글자. 찾으면 그 대사로 (목록에서 누른 것과 같음)
  - [고급]을 펼치면 더 찾기: 클립 이름 · 마커 이름 · 대사 메모 (대본). 클립 · 마커를 찾으면 그것이 골라지고 재생 위치가 거기로
  - 치는 대로 지금 위치부터 처음 맞는 것으로 바로 이동 (이미 맞는 것 위면 그대로). 녹음 중에는 개수만 보여 주고 Enter로만
    이동 (다른 대사로 가면 녹음이 멈추니까)
  - "2/5"처럼 지금 몇 번째인지와 개수, 없으면 "0개". Enter = 다음, Shift+Enter = 이전 (끝에서 처음으로 돌아감), ▲▼ 버튼도
  - 찾기 칸이 열린 채로 작업 가능. Esc 또는 ✕로 닫음. 열 때마다 빈 칸, 고급은 접히고 꺼진 채로 (지난 선택 기억 안 함)
- 빈 프로젝트일 때: "파일을 끌어다 놓거나 Ctrl+O" 안내
- 어두운/밝은 테마, 화면 크기, 트랙 높이 (설정, 마지막 선택 기억)
- 단축키 창 (F1): 모든 단축키 목록 + [단축키 바꾸기…]

## 3. 재생 / 녹음
- 재생/일시정지 (Space), 정지 (설정: 처음 시작 위치로 복귀 / 멈춘 자리에 남기). 들을 소리가 없으면 (빈 프로젝트, 테이크 없는 대사) 재생 버튼이 회색이고 Space도 아무 일 안 함
- 재생 중 화면이 재생 위치를 따라감 (설정에서 끄기)
- 눈금 클릭 = 재생 위치 이동, 눈금 드래그 = 위치 훑기
- 반복 재생 (L): 선택 구간이 있으면 그 구간을 끊김 없이 반복 (메트로놈도 바퀴마다 박자에 맞춤). 반복 중 구간을 끌어 바꾸면
  마우스를 놓을 때 새 구간으로. 1ms보다 짧은 구간은 소리가 거칠어짐
- 메트로놈 (K): 빠르기·박자대로 딸깍 소리, 마디 첫 박은 높은 소리. 들리기만 하고 내보내기엔 안 들어감. 볼륨은 설정.
  재생·녹음 중에 켜고 끄거나 BPM·볼륨을 바꾸면 멈추지 않고 바로 반영
- 녹음 메뉴: 녹음 · 이어 녹음 | 긴 녹음 나누기… | 메트로놈 (이어 녹음 · 긴 녹음 나누기는 대본 모드에서만)
- 녹음 (R): 재생 위치부터 새 트랙에 마이크 녹음, 다른 트랙은 함께 재생 (겹쳐 녹음). 다시 R/Space로 정지
  - 카운트인 (설정: 끄기 / 1마디 / 2마디): 녹음 전에 박자 소리를 먼저 들려줌. 메트로놈이 켜져 있으면 다음 격자 박으로 이어짐
  - 마이크·모노/스테레오는 설정. 고른 마이크가 없으면 기본 마이크로 녹음하고 알려 줌
  - 녹음 지연 보정 (설정, ms): 다른 트랙과 박자가 맞게 녹음을 앞으로 당김. [자동 측정] 가능
- 녹음 중 파형 실시간 표시
- 레벨 미터: 믹서의 트랙·마스터, 설정의 마이크 테스트. 0 dB를 넘으면 빨간 클리핑 표시 (눌러서 지움)

## 4. 편집
- 구간 선택: 트랙 빈 곳/클립 몸통을 드래그 (위아래로 끌면 여러 트랙에 걸쳐 선택), Shift+클릭으로 늘리기
- 클립 선택: 클립 이름 띠 클릭 (Ctrl+클릭으로 여러 개)
- 클립 이동: 이름 띠를 드래그 (좌우 = 시간, 위아래 = 다른 트랙)
- 스냅 (G): 끌 때 클립 끝·재생 위치·마커(박자 격자 켜면 박자)에 붙음. 끄면 자유롭게
- 클립 끝 다듬기: 클립 양쪽 끝을 드래그해서 앞뒤 잘라내기 (원본 범위 안에서 다시 늘리기 가능)
- 페이드: 클립 위쪽 모서리의 작은 네모를 끌어 페이드 인/아웃. 클립 볼륨·페이드 창(편집 메뉴, 오른쪽 클릭)에서 숫자로도
  - 모양: 직선 · 부드럽게(S자) · 빠르게(처음에 확 바뀜) · 천천히(끝에 확 바뀜). 네모를 오른쪽 클릭하거나 클립 볼륨·페이드 창,
    효과 > 페이드 인/아웃 창에서 고름. 새 페이드는 언제나 직선 (기억 안 함). 자동 크로스페이드는 늘 직선
- 겹친 클립: 일부만 겹치면 겹친 부분이 자동으로 크로스페이드 (소리가 튀지 않게)
- 클립 나누기 (S): 재생 위치에서 (선택된 클립 또는 선택 트랙)
- 클립 합치기 (Ctrl+J): 같은 트랙에서 선택한 클립들 / 선택 구간 안의 클립들을 하나로 (사이 빈 곳은 무음)
- 복제 (Ctrl+D): 선택 클립을 바로 뒤에 복사
- 잘라내기 / 복사 / 붙여넣기 (Ctrl+X/C/V)
- 삭제 (Delete): 구간 선택 → 그 구간을 지우고 뒤를 당김 / 클립 선택 → 클립만 지움 / 마커 선택 → 마커 지움
- 선택만 남기기 (Ctrl+T), 무음 넣기 (선택 길이만큼 / 길이 입력)
- 마커: M = 재생 위치에 추가, [ / ] = 이전/다음 마커로, 눈금의 마커를 끌어 옮기기, 더블클릭 = 이름 바꾸기,
  오른쪽 클릭 = 이름 바꾸기/삭제. 실행취소 대상. 모든 트랙에 걸친 삭제·삽입·붙여넣기를 하면 함께 움직임
- 선택 구간 확대 (Ctrl+Shift+F): 선택 구간이나 선택 클립이 화면에 꽉 차게
- 실행취소 / 다시실행 (Ctrl+Z / Ctrl+Y, Ctrl+Shift+Z)
- 오른쪽 클릭 메뉴: 위 편집 동작 모음

## 5. 효과 (선택 구간 → 없으면 선택 클립 → 없으면 전체)
- 맨 위 '목소리 정리' 묶음 (흐린 작은 제목 아래 7줄):
  - 한 번에 깔끔하게: 줄마다 [끄기 · 약하게 · 보통 · 강하게] (음량 줄은 [끄기 · 작게 · 보통 · 크게]) — 잡음 줄이기 → 저음
    정리 → 목소리 고르게 → 긴 침묵 줄이기 → 음량 맞추기, 처음엔 모두 보통. 창은 언제나 이 줄로 열림 (기억하지 않음)
  - 음량 맞추기 [작게 · 보통 · 크게] = -23 · -16 · -14 LUFS (숫자는 버튼 아래 작게), 트랙마다 따로, 튀는 소리는 -1dB에서 막음
  - 긴 침묵 줄이기 (약하게 1.5초 넘는 쉼 → 1초 · 보통 1초 → 0.5초 · 강하게 0.7초 → 0.3초): 말 사이는 양쪽에 반씩.
    맨 앞 · 맨 끝 쉼은 길이와 상관없이 언제나 그 길이 (1 · 0.5 · 0.3초)로 딱 맞춤 — 길면 자르고 짧으면 완전한 무음을
    덧붙임 (소리가 바로 시작해도 앞에 그만큼). 앞뒤 쉼은 들리는 첫 · 마지막 소리부터 잼: 숨소리 · 작게 끝나는 말끝도 소리,
    말소리보다 35dB 넘게 작은 꼬리 · 울림은 조용한 것 (말 사이에서는 숨소리도 조용한 걸로 봄). 잴 때만 150Hz 아래
    웅웅거림을 빼고 잼 (소리는 그대로). 조용한 곳이 0.5초도 없어 잡음 크기를 못 재면 말소리 크기로만 판단 (건너뛰지 않음). 구간을 골랐으면 녹음의 진짜 앞뒤만 (구간 끝이 녹음 중간이면 그 끝은 그대로).
    트랙마다 그 트랙의 쉼을 줄임 (마커는 트랙이 하나뿐일 때만 따라감)
  - 목소리 정리 창은 언제나 같은 값으로 열림 (효과 하나짜리 = 보통, 한 번에 깔끔하게 = 위 줄). 마지막 선택을 기억하지 않음
  - 치찰음 줄이기 (5kHz 위를 3 · 6 · 10dB), 전기 웅 소리 지우기 (50/60Hz 자동, 배수 1 · 3 · 5개), 작은 잡음 끄기 (-10 ·
    -20dB · 완전히), 목소리 고르게 (컴프 프리셋 부드럽게 · 목소리 고르게 · 팟캐스트)
  - 창 = 세기 버튼 + 미리듣기 · 취소 · 적용 (숫자 칸 없음, 처음엔 보통, Enter = 적용). 실행취소 한 번
  - 잡음 크기는 고른 구간에서 가장 조용한 0.5초로 자동 (빈 곳의 완전한 무음은 빼고 잼). 못 재면 그 단계만 건너뛰고 알림
    ('잡음 줄이기는 건너뛰었어요 — 조용한 부분이 없어서'), 효과 하나만 눌렀으면 아무것도 안 바뀜
- 볼륨 조절 (dB), 정규화 (최대 레벨 dB)
- 페이드 인 / 페이드 아웃
- 무음 처리, 역재생
- 속도 바꾸기 (음높이 유지, %), 음높이 바꾸기 (길이 유지, 반음)
- 잡음 줄이기: ① 잡음만 있는 구간 선택 → "잡음 프로필 잡기" ② 처리할 구간 선택 → 적용 (감소량, 민감도)
- EQ: 로우컷, 저음 + 저음 기준 주파수, 중음 + 중음 주파수 + 중음 폭, 고음 + 고음 기준 주파수, 하이컷.
  **EQ 그래프**: 주파수 곡선의 점을 끌어서 조절 (좌우 = 주파수, 위아래 = 세기, 휠 = 중음 폭, 더블클릭 = 원래대로).
  아래 슬라이더로도 똑같이 조절 (키보드용)
- 컴프레서: 임계값, 비율, 어택, 릴리즈, 메이크업 게인
- 리버브: 공간 크기, 잔향 길이, 섞는 양(wet), 밝기
- 에코/딜레이: 간격(ms), 반복(피드백), 섞는 양
- 효과 창에서 "미리듣기" (선택 구간 앞부분 최대 10초, 처리된 소리로 재생)
- 효과 창 맨 위에 [프리셋 ▾] — 고르면 슬라이더 값이 바뀜 (아래 §5-2)

## 5-1. 항상 걸린 효과 — 마스터 + 트랙 (오른쪽 효과 패널)
- 효과 패널 (F8 / 위 바 버튼)로 열고 닫음 (마지막 상태 기억). 맨 위에서 채널 고르기: 마스터 또는 트랙
- 지금 보는 채널 구분: 맨 위 색 띠(트랙 = 그 트랙 색, 마스터 = 청록 — 믹서 마스터 줄과 같은 색), 큰 제목
  '트랙 효과 · 이름' / '마스터 효과 · 전체 소리에', 안내 '이 트랙에만 걸려요' / '모든 트랙이 섞인 뒤에 걸려요',
  효과 카드 왼쪽 테두리도 같은 색
- 믹서의 채널 이름이나 [효과] 버튼, 트랙 헤더의 효과 버튼을 누르면 그 채널의 효과가 나옴
- 원본은 안 바뀜. 재생 중에 바꾸면 바로 들림. 내보내기에도 그대로 적용
- 트랙 효과 순서: 전기 웅 소리 → EQ → 컴프레서 → 치찰음 줄이기 → 리버브 → 에코 → (트랙 볼륨·팬)
- 전기 웅 소리 (전기 주파수 50/60Hz, 지우는 개수 1~5): 켤 때 그 트랙(캐릭터면 그 캐릭터 테이크)의 소리를 한 번 들어 50/60Hz를
  골라 둠. 프리셋은 지우는 개수만 바꾸고 전기 주파수는 그대로 (녹음 장소의 성질). 치찰음 줄이기 (줄이는 양 0~20dB, 기준 높이
  3~10kHz)
- 마스터 효과: 모든 트랙이 섞인 최종 소리에. 순서: EQ → 컴프레서 → 리버브 → 에코 → 마스터 볼륨 → 리미터
- 카드마다: 켜기/끄기, [프리셋 ▾], 슬라이더 (더블클릭 = 기본값). 꺼진 카드는 접힘. EQ 카드에는 EQ 그래프
- 마스터 볼륨: -24 ~ +12 dB (항상 켜짐, 믹서 마스터 페이더와 같은 값)
- 리미터 (마스터만): 최대 레벨(-6 ~ 0 dB), 입력 게인(0 ~ 12 dB). 최대 레벨을 절대 넘지 않음
- 리버브·에코가 켜져 있으면 내보내기 끝에 잔향 꼬리까지 포함
- 효과 설정은 프로젝트 파일에 저장됨. 실행취소 대상 아님 (믹서와 같음)

## 5-2. 기본 프리셋 (효과 패널 카드 + 효과 창 공용)
| 효과 | 프리셋 |
|---|---|
| EQ | 목소리 또렷하게 · 웅웅거림 줄이기 · 라디오 느낌 · 따뜻하게 · 밝게 |
| 컴프레서 | 목소리 고르게 · 팟캐스트 · 부드럽게 · 강하게 · 음악 전체 |
| 리버브 | 작은 방 · 은은하게 · 목욕탕 · 홀 · 성당 |
| 에코 | 짧은 슬랩백 · 메아리 · 산울림 · 120BPM 박자 |
| 리미터 (마스터만) | 기본 · 크게 · 유튜브 크게 |
| 전기 웅 소리 · 치찰음 줄이기 | 약하게 · 보통 · 강하게 (목소리 정리의 같은 이름과 같은 값) |
| 잡음 줄이기 (효과 창만) | 약하게 · 보통 · 강하게 |
내 프리셋 저장은 없음 (기본 프리셋만). 값이 어느 프리셋과도 다르면 "직접 조절"로 보임.

## 5-3. 설정 (Ctrl+,) — 바꾸면 바로 적용, 다음에 켜도 기억
- 오디오 장치: 마이크, 입력 레벨 테스트, 스피커, 녹음 채널(모노/스테레오), 녹음 지연 보정(ms) + 자동 측정
- 녹음 · 재생: 카운트인(끄기/1마디/2마디), 메트로놈 볼륨, 재생 중 화면 따라가기, 정지하면 시작점으로
- 파일 · 프로젝트: 자동 저장(끄기/1/2/5/10분), 기본 내보내기 형식, 새 프로젝트 샘플레이트(44.1/48 kHz),
  실행취소 메모리(되돌리기 기록만 0.5/1/1.5/3 GB, 기본 0.5), 최근 파일 목록 지우기
- 화면 · 단축키: 테마, 화면 크기(90~125%), 트랙 높이(작게/보통/크게), 단축키 바꾸기 (기능마다 [바꾸기]/[기본값],
  다른 기능이 쓰던 키면 그 기능에서 빠지고 알려 줌), 단축키 모두 기본값으로

## 5-4. AI용 CLI (명령줄) — 사용법: `docs/cli.md`, `sori --help`
클로드 같은 AI(사람도)가 터미널에서 프로젝트를 다룸. 실행: Sori 폴더에서 `node src/cli/sori.js …` (`npm link` 하면 `sori …`).
결과는 언제나 JSON 한 줄 (성공 `ok: true` / 실패 `ok: false` + 이유).
- ① 파일 명령 (앱을 안 켜도 됨): 정보 보기(`info`), 새 프로젝트, 트랙 추가(빈 · 목소리 · 배경음악 · 효과음 · 복제)·삭제·순서·
  이름/볼륨/팬/M/S, 소리 불러오기, 항상 걸린 효과(트랙·마스터, 프리셋), 효과 메뉴 효과(목소리 정리, 볼륨 조절 ~ 에코, 잡음 줄이기),
  클립 옮기기·지우기·나누기·볼륨/페이드(곡선까지)·끝 다듬기·합치기, 구간 삭제·남기기·무음 넣기, 마커 추가·삭제·이름·위치,
  빠르기·박자·격자, 내보내기(WAV/MP3, 전체·구간·지금 트랙만·마커 구간별). 규칙은 앱과 같음 (마커 따라가기, 트랙 위치 등)
  - 바로 저장되고 실행취소는 없음. 소리 불러오기·내보내기는 보이지 않는 창으로 처리 (앱을 켜 둔 채로도 됨, 설정·자동 저장은 안 건드림)
  - 앱에서 그 프로젝트를 열어 두었으면 고치는 명령은 거절 (양쪽 작업이 사라지지 않게) → 같은 명령을 `sori live …`로
  - 트랙 색 바꾸기는 CLI에만 (`track set --color F472B6`, 아무 헥스 코드). 앱에는 고르는 곳이 없고 보여 주기만 함
  - 여러 명령 한 번에 (`batch`, 켜 둔 앱은 `live batch`): 한 줄에 명령 하나 적은 파일 (또는 `-`로 바로 넘기기). 모든 줄을
    먼저 검사하고 적은 순서대로 함, 하나라도 실패하면 아무것도 저장 · 반영 안 함 (몇 번째 줄인지 알려 줌), 앱에서는
    Ctrl+Z 한 번에 묶음 전체. 줄마다 건드리는 곳(대사 · 캐릭터 · 트랙 · 마커 · 템포 · 전체)과 동시에 해도 되는 묶음을
    알려 줌 (`--check`는 실행 없이 판단만). 내보내기는 묶음에 못 넣음
  - 소리 재기 (`measure`, `live measure`): AI는 못 들으니 들리는 그대로(트랙 · 캐릭터 효과와 마스터까지, 내보내기와 같은
    소리)를 숫자로: 음량(LUFS), 최대 크기, 0dB 넘어 잘린 곳 (개수 + 앞에서 20곳 시각), 방 잡음, 말소리 크기, 조용한 곳이
    0.5초 넘게 이어진 구간 (긴 침묵 줄이기와 같은 기준). 보통 프로젝트는 트랙마다 + 전체, 대본은 대사마다 ★ 테이크
    (`--char`, `--line`, `--take`), `--from` / `--to`로 구간만. 아무것도 바꾸지 않음
  - 여러 대사 목소리 정리 (`apply voiceX`, 대본 프로젝트): `--line 철수-001,영희-003` · `--char 철수` · `--all-lines`로
    여러 대사의 ★ 테이크에 한 번에. 대사마다 CPU 여러 개로 동시에 계산하고, 반영은 한 대사씩 한 것과 똑같음. ★ 없는
    대사는 건너뛰고 알려 줌. 목소리 정리 메뉴만 되고 (다른 효과는 한 대사씩), 모든 대사는 `--all-lines`를 꼭 적어야 함.
    앱 창에는 없음 (명령줄에만)
- ② live 명령 (켜 둔 앱): CLI로 모든 걸 할 수 있음. 지금 상태 보기, 메뉴 명령 목록, 선택(구간·클립·지금 트랙·마커·재생 위치),
  메뉴 명령 실행, 앱이 기억하는 설정 전부 보기 · 바꾸기 (`live settings --theme light`, `--metronome on`, 자동 측정
  `--latencyMs auto`, 마이크 테스트 `--mic-test 2`, 단축키 `--key split=Ctrl+K` · `--keys default`, 최근 파일 `--recent clear`),
  그리고 ①의 파일 명령 전부를 켜 둔 프로젝트에 (`sori live track set --track 1 --volume -3`, `sori live script import 대본.txt`,
  파일 이름 없이; 새 프로젝트만 `live run newProject`).
  화면에 바로 보이고, 앱에서 Ctrl+Z로 되돌릴 수 있는 것(트랙 · 클립 · 마커 · 대사)은 Ctrl+Z 한 번으로 되돌림.
  창이 뜨는 명령(이름 끝 …)은 값을 같이 주면 창 없이 실행, 파일 고르는 창은 `--path`, 묻는 창은 `--yes`로 대신 답함.
  안 주면 사용자 화면에 창이 뜸
  - 이 컴퓨터 안에서만 연결 (네트워크 안 씀). 앱의 명령 이름만 받고 값은 그 창의 칸 범위로 검사
- 대본 명령 (`sori script`, docs/cli.md): 보기 · 대본 넣기 · 보통 프로젝트로 바꾸기 (둘 다 `--dry-run` 미리 보기) · 대사 고치기 ·
  테이크 넣기 / 지우기 / 순서 · 테이크 이름 · 볼륨 · 팬 · ★ · 캐릭터 효과 · 캐릭터 색 · 대사별 내보내기 · 긴 녹음 나누기
  (`script split`: 경계는 `--cut` 초 또는 `--every-gap`, `--join` = 대사마다 한 테이크). 켜 둔 앱: `live script line 철수-001`, `live script star 3`, `live script view --char 철수 --todo on` (목록 보기).
  규칙은 앱과 같음 (대사 번호는 선택, ★는 저절로 안 옮김). 대본 프로젝트에선 `clip` · `range` · `apply` · `import` · `fx`가
  `--line 철수-001 --take 2`로 그 대사의 테이크에 (앱에서 테이크가 트랙 자리이듯). 테이크에 없는 것(트랙 추가 · 지우기 · 옮기기 ·
  값)과 `info` · `export`는 거절 (`SCRIPT_PROJECT`, 쓸 `script` 명령을 알려 줌)

## 5-5. 대본 녹음 모드 (게임·애니 보이스 납품식: 대사마다 파일 하나)
- 대본 넣기: 파일 > 대본 넣기… → 지금 프로젝트가 대본 프로젝트가 됨 (트랙이 있으면 "트랙 n개가 모두 지워지고…" 경고창 뒤 지움),
  대사마다 "캐릭터-번호" (번호는 대본에 적으면 그대로 — 1-01, A3 같은 글자도, 안 적으면 자동). Ctrl+Z 한 번이면 원래 프로젝트로
  - 마크다운에서 복사한 대본의 `\[` `\~` 같은 역슬래시(문장부호 앞)는 빼고 넣음 (예전에 넣은 대본도 열 때 고침)
  - .txt: 한 줄에 `이름: 대사` (또는 `이름-005: 대사`). 이름 없는 줄은 위 대사에 이어 붙음, 빈 줄과 `#` 줄은 무시, `(지문)`은 메모
  - 엑셀 / CSV: 열 = 캐릭터 | 대사 (번호 · 메모 열은 있으면 씀). 머리글이 없으면 1열 캐릭터 · 2열 대사
- 화면: 왼쪽 대사 목록 + 위쪽 대사 띠 + 오른쪽 타임라인(고른 대사의 테이크만)
  - 목록: [전체] [캐릭터별] 탭 (진행률 철수 1/2), '녹음 안 한 것만' 스위치 (완료된 대사는 지금 대사라도 바로 빠짐), 대사마다 번호 · 대사 · 메모 ·
    테이크 수 (★ 있으면 ★) · '다시 녹음 필요' 표시. 누르면 그 대사로, 더블클릭 = 대사 고치기
  - 대사 띠: 지금 대사를 크게 + 메모. 녹음 중에는 더 크게(프롬프터) + 다음 대사를 작게
- 녹음: 대사 고르고 R = 새 테이크 ("테이크 n", 0초에서 시작). 멈추면 같은 대사에 머물고, 방금 녹음한 테이크가 골라짐
  (Space = 방금 녹음한 것). 오디오 파일을 끌어 놓아도 같음. 위쪽 '테이크 n개' 옆 [+ 테이크] (Ctrl+Shift+N) = 맨 아래에 빈
  테이크 "테이크 n"이 생기고 골라짐, ★는 그대로 (붙여넣기 할 자리; 녹음 중엔 흐리게, Ctrl+Z로 되돌림)
  - 테이크는 언제나 모두 보임: 녹음한 순서대로 (★는 표시만, ★를 옮겨도 순서 그대로), 테이크 머리 위에 '테이크 n개' 글자.
    대사로 오면 ★ 테이크가 골라짐 (★가 없으면 첫 테이크). 누른 테이크가 골라지고, 재생하면 고른 테이크가 들림
  - 재생 중에는 듣던 테이크가 멈출 때까지 계속 들림: 다른 테이크를 누르거나 ★를 옮겨도 바뀐 것은 다음 재생부터.
    다른 대사로 옮기면 (↑/↓, 목록, Ctrl+Z가 다른 대사로 갈 때) 재생 · 녹음이 멈춤 (보는 대사만 바뀜)
  - ★ = 내보낼 테이크. 사람만 옮김: 테이크 머리의 ★ 버튼 (Ctrl+Z로 되돌림). 테이크에는 M · S가 없음 (★가 M 자리, 믹서에서도 숨김)
  - ↓ / ↑ = 다음 / 이전 대사 (목록에 보이는 순서; 녹음 중이면 녹음을 멈추고 테이크는 남김, 재생 중이면 멈춤). 테이크 지우기 = 테이크 머리의 ✕ (Ctrl+Z로 되돌림)
  - 테이크도 보통 클립처럼 자르기 · 페이드 · 효과 메뉴를 그대로 씀
- 긴 녹음 나누기: 대사를 하나씩 녹음하지 않고 길게 한 번에 녹음해 대사별 테이크로 나눔. 두 길 모두 같은 확인 창으로 감
  - 이어 녹음 (Shift+R, 녹음 메뉴): 지금 대사부터 멈출 때까지 한 녹음. 테이크는 녹음 중에 생기지 않음. 타임라인에는 테이크 아래
    '이어 녹음' 줄에 파형이 자라고 N을 누른 곳마다 세로선. 대사 띠(프롬프터)가
    짝지어질 대사를 크게, 그다음 대사를 작게 보여 주고 녹음 시간 · 입력 크기를 표시. 목록에서는 그 대사에만 빨간 테두리.
    대사 띠 오른쪽 [이어 녹음] 버튼으로도 시작 · 멈춤
    - N = 다음 대사 (대사 띠가 넘어가고 녹음에 경계가 찍힘, 마지막 대사에서는 알림만), Shift+N = 마지막 N 되돌리기 (녹음은 계속)
    - 다시 Shift+R (또는 R · Space) = 멈춤 → 확인 창. ↑/↓ · 목록에서 다른 대사 누르기도 멈추고 확인 창 (보는 대사는 바뀜)
    - 이어 녹음 중에는 새로 만들기 · 열기 · 대본 넣기 · 닫기가 안 됨 ("Shift+R로 멈추고 나눈 뒤에") — 녹음이 확인 창에만 있어서.
      확인 창이 열려 있을 때도 앱 창 ✕ · 밖에서 프로젝트 열기는 알림만 ("적용하거나 버린 뒤에")
  - 긴 녹음 나누기… (녹음 메뉴): 이미 녹음한 긴 파일을 골라 지금 대사부터 나눔 (N 표시 없음)
  - 대사 경계는 언제나 사람이 정함: 녹음 중 N, 또는 확인 창에서. N은 누른 순간 앞뒤 2초 안에서 가장 가까운 쉬는 곳(0.2초 넘는
    쉼)의 가운데에 찍힘 (없으면 누른 순간). 쉬는 곳은 한 대사 안에서 조각만 나눔: 쉬는 기준(처음 1초, 0.3~5초)보다 길게 쉰
    곳에서 잘림. 0.3초보다 짧은 소리는 조각이 아님. 조각마다 말 앞뒤로 쉬는 소리를 0.3초씩 남김 (옆 조각 · 경계와의 가운데까지만)
  - 짝짓기: 시작할 때의 대사부터 왼쪽 목록에 보이는 순서 (캐릭터 탭 · '녹음 안 한 것만'을 따름). 대사보다 많은 조각은 넣지 않음
  - 확인 창: 위에 긴 녹음 전체 파형 (조각 · 대사 경계, 누르면 그 조각), 그 아래 고른 조각과 앞뒤 1초 파형 (조각 양 끝을 끌어
    옮김, 누르면 나눌 곳), 도구, 대사별 조각 목록 (대사 이름 아래 조각들, 버린 조각은 흐리게 '버림')
    - 듣기 (Space, 조각 더블클릭), 합치기 (Ctrl+J, Ctrl/Shift+클릭으로 둘 넘게 골라: 사이에 쉰 소리도 그대로 한 테이크),
      나누기 (S, 아래 파형에서 누른 곳), 버리기 · 되살리기 (Delete), 여기부터 다음 대사 (N), 대사 경계 지우기,
      쉬는 곳마다 대사 나누기 (모든 조각 사이에 경계), 대사 고르기 (고른 조각의 대사를 바꾸면 뒤 대사들도 그다음부터 이어짐),
      ↑/↓ 조각 이동 (Shift = 함께 고르기). 할 일이 없는 도구는 흐리게
    - 마우스 없이: ←/→ 나눌 곳 (처음엔 조각 가운데), Alt+←/→ 조각 시작, Alt+Shift+←/→ 조각 끝 (0.1초씩)
    - 창 안 되돌리기: Ctrl+Z / Ctrl+Y (Ctrl+Shift+Z). 창을 닫으면 사라지고, 적용은 앱의 Ctrl+Z 한 번으로 되돌림
    - 파형: 전체에는 대사 이름, 아래에는 시간 눈금. 듣는 동안 재생 위치선이 움직이고 버튼은 '멈추기'
    - 쉬는 기준을 바꾸면 조각을 처음부터 다시 나눔 (대사 경계는 그대로). 손본 조각이 있으면 창 안에서 먼저 물어봄
    - [적용 (테이크 n개)]: 조각마다 그 대사의 새 테이크 ("테이크 n", 0초에서), ★ 없던 대사는 첫 새 테이크가 ★. Ctrl+Z 한 번에
      전부 되돌림. 긴 녹음 원본은 남기지 않음
    - [취소] / Esc / ✕: 파일에서 나눴으면 그냥 닫힘. 이어 녹음이면 "나누지 않고 닫으면 이 녹음은 사라져요" [돌아가기] [버리고 닫기]
- 효과: 캐릭터마다 한 벌 (효과 패널 '캐릭터 · 철수') → 그 캐릭터의 모든 대사 · 테이크에. 마스터 효과도 걸림
- 대본 바뀔 때: 대본 프로젝트에서 파일 > 대본 넣기… = 새 대본이 기준 (같은 이름끼리 녹음을 이어 줌, 새 대본에 없는 대사는 테이크째
  지움, 바뀐 개수를 먼저 보여 주고 [취소] [바꾸기]) + 편집 > 대사 고치기… (대사 · 메모)
- 보통 프로젝트로 바꾸기: 파일 > 보통 프로젝트로 바꾸기… → 경고창 → 테이크마다 트랙 하나 ("철수-001 테이크 1", 0초에서, 대본 순서 →
  녹음 순서, 캐릭터 색 · 효과 그대로). 대사 · 메모 · ★는 사라짐, Ctrl+Z로 되돌림. 녹음 중에 누르면 (대본 넣기도) 녹음을 먼저 멈춤
- 내보내기 (Ctrl+E): 형식 · 범위(전체 / 캐릭터 고르기 / 지금 대사) → 폴더 → ★ 테이크를 "캐릭터-번호.wav" (전체 · 캐릭터
  고르기는 그 폴더 안 새 폴더 '프로젝트 대사 날짜 시각'/캐릭터/에, 지금 대사는 그 폴더에 바로). 들리는 그대로
  (캐릭터 효과 + 마스터 효과). 녹음 안 한 대사는 건너뛰고 몇 개인지 알림. '다시 녹음 필요' 대사도 ★가 있으면 내보내고 개수 알림
- 저장: .vproj에 대본 · 테이크 · ★ · 캐릭터 효과까지
